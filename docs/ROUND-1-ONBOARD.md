Reproducible macOS conversion (requires ffmpeg with VideoToolbox; no `-y`, no original modification):

```sh
ffmpeg -i "$HOME/Downloads/copy_82E96ABF-E74F-43B0-8078-9CBA9E1F420A.MOV" \
  -map 0:v:0 -map '0:a:0?' -c:v h264_videotoolbox -b:v 6M \
  -pix_fmt yuv420p -profile:v high -tag:v avc1 \
  -c:a aac -b:a 160k -movflags +faststart \
  "$HOME/Movies/RKS/2026/rks-2026-r1-tyler-1080p.mp4"
```

## Data and UX contract

- R1 only, driver `DRV_TYLER`, Kart 67, official finish P1.
- All 19 displayed lap times resolve directly to `raceLapRecords2026`; no duplicated timing arrays.
- Video starts/ends come from the owner's notes. They are **not** generated by summing timing-system laps.
- Source end timestamps are inclusive whole seconds; active detection uses `[start, end + 1)` so fractional seconds do not leave gaps.
- Source typo corrections: Lap 14 `35:21 → 36:21`, Lap 18 `40:31 → 41:31`. These affect video seeking only.
- `?onboard=tyler&lap=18` seeks to 2491 seconds; `?onboard=tyler&t=2102` seeks directly. Lap has precedence when both appear. Invalid parameters do not trigger a seek.
- URL changes use `history.replaceState`, preserving current history state and unrelated query parameters, without route reloads. Initial seeking is applied when video metadata becomes available. Browser history changes re-read deep links.
- Timeupdate drives active session/lap. Seeking does not autoplay, preserving mobile autoplay policies.
- Theater expands the player from the split layout to full content width; fullscreen is a separate Fullscreen API action with native WebKit video fallback. Escape exits theater.
- Shortcuts apply inside the focused player, excluding controls and editable elements. Buttons/selects/ranges retain normal keyboard behavior.
- Dynamic import is rendered only for an event with an available media record; metadata preload, no autoplay, no homepage player. The media file is never bundled.
- Future annotations are typed but the annotations array is empty.
